# Klipper Configuration Snapshot

These files are reference material for this CR-10 V3 conversion. They are not guaranteed to be safe on another printer without review.

Before use:

- Set the correct MCU `serial:` path in `printer.cfg`.
- Confirm every pin assignment against your exact MKS Robin Nano v3.1 board.
- Verify motor direction, endstop state, thermistor type, heater behavior, probe operation, and emergency stop behavior.
- Do not heat or move the printer until the config is checked.
